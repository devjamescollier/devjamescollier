# James Collier

## Welcome to my GitHub!

Hi! My name is James. I am a student studying Electrical and Computer Engineering at the University of Southern California with an emphasis in *Systems, Signals, and Learning*. I enjoy designing and building PCBs and writing embedded firmware.

### My Stack
I program embedded systems and firmware for my PCBs primarily in C and C++, and I use Verilog and SystemVerilog as my hardware description languages, with Neovim being my primary text editor. I typically work with ESP32, STM32, and ATmega328P boards. I develop PCBs using Altium Designer and KiCad, with LTspice for simulation purposes, and STMCubeIDE for pinout. I occasionally write test suites and interfaces in Python, and I use MATLAB.
